# 验证记录

记录运行编号、日期、候选人版本、规则版本、材料范围、岗位数量、主表/待核验/筛除数量、人工发现问题、改动与耗时。

检查所有岗位有记录；门槛先处理；分数可追溯到原文、证据、理由和公式；简历无未经确认事实；Excel可读，输入变化后分数更新，排序是否需手动刷新如实说明。

比较效率时使用相近复杂度和相同数量JD，记录人工处理及工作流处理总耗时，包含补充、核验和纠错。没有实测就写未测量，不承诺提升比例。记录门槛漏判、来源错误、无依据判断与简历新增事实。

公开使用脱敏副本，移除联系信息、私人账号、会话链接、保密数据及未经授权截图。合成数据明确标注，不将合成测试写成真实求职效果。

检查范围边界：业务分析岗位使用SQL不自动排除；以开发软件为核心的岗位记超出范围；没有明确职责时等待补充。
